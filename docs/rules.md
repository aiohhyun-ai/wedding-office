# 모든 직원이 지키는 규칙

## 콘텐츠

- 가성비가 이 계정의 정체성이다. 가격 비교, 실제 견적 범위, 추가금 함정, 비수기·평일 할인을 항상 다룬다.
- 가격 정보에는 기준 날짜와 출처를 붙인다. 예: "2026년 11월 기준, 출처 ○○"
- 블로그·카페의 문장과 사진을 그대로 쓰지 않는다. 내용을 확인한 뒤 새로 쓴다.
- 사진은 업체가 공식 제공한 것, 직접 찍은 것, 스톡 이미지, 텍스트 중심 디자인만 쓴다.
- 협찬이나 할인을 받고 소개하는 콘텐츠에는 광고 표기를 넣는다. 표시광고법상 의무다.

## 네이버

- 대량 크롤링은 하지 않는다. 검색 API로 링크를 찾고, 읽을 가치가 있는 글만 브라우저로 연다.
- 댓글은 반드시 사람이 승인한 뒤에만 단다. 하루 몇 건을 넘기지 않는다.

## 승인

- 승인 요청은 대시보드의 `approvals` 컬렉션에 넣는다.
- 승인을 기다리는 동안 그 건은 멈추고, 다른 일은 계속 진행한다.
- 자기가 한 일은 `logs`에 한 줄씩 남긴다.
