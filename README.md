# wedding-office

결혼 준비 가성비 정보 인스타그램 계정을 운영하는 AI 오피스.

## 구조

- `agents/` 직원(에이전트)별 역할 지시문. Claude 예약 작업에 붙여서 쓴다.
- `scripts/` 네이버 검색, 인스타그램 게시·인사이트 스크립트
- `docs/` 운영 규칙과 연결 정보

## 직원

| 파일 | 직원 | 하는 일 | 언제 |
|---|---|---|---|
| `agents/scout.md` | 트렌드 스카우트 (여우) | 콘텐츠 주제 제안 | 매일 아침 |
| `agents/researcher.md` | 리서처 (고양이) | 승인된 기획의 카페·블로그 조사 | 기획 승인 직후 |
| `agents/mail.md` | 우편 담당 (펭귄) | 대댓글·메일 자료 확인 | 하루 2번 |
| `agents/planner.md` | 기획자 (곰) | 카드뉴스·릴스 기획 | 조사 완료 후 |
| `agents/designer.md` | 디자이너 (개구리) | 디자인 제작 | 기획 승인 후 |
| `agents/publisher.md` | 게시 담당 (강아지) | 인스타그램 업로드 | 디자인 승인 후 |
| `agents/analyst.md` | 분석가 (부엉이) | 반응·트렌드 분석 | 매주 월요일 |

## 일이 넘어가는 방식

직원들은 서로 대화하지 않는다. 업무 보드(대시보드 DB)의 `state` 값만 보고 자기 일을 가져간다.

```
idea → (기획 승인) → research → planning → (기획안 승인) → design → (디자인 승인) → ready → posted → analyzed
```

승인이 필요한 지점은 세 곳이다. 기획 승인, 댓글 승인, 최종 디자인 승인.

## 비밀값

API 키와 토큰은 이 저장소에 넣지 않는다. `.env`는 커밋하지 않는다.
